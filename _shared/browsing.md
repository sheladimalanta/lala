# Browsing

Browsing is a step inside other work, so it has no lane.

1. **Public page:** use web fetch, with no browser or login.
2. **Logged-in page:** use the browser profile for this session's area. Never sign
   in to another area's account there.
3. **The same collection keeps repeating:** stop. Tell Shela there is no scraping
   lane yet, and route to `~/lala/CONTEXT.md`, "A new lane".

Sending, submitting or publishing anything from a browser needs Shela's approval.
