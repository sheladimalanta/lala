The three kinds of things

Each kind has its own color in the map.

What to know

Instructions that Claude reads and usually follows, but can decide not to.

What it can do

Skills, helpers and connected tools that Claude can use when a task needs them.

What must happen

Settings and hooks that Claude Code applies itself. Use these for rules that can't have exceptions.

What actually loads

Where you start Claude Code decides which folders count, so start in the area or project you're working on.

When a session starts

CLAUDE.md files from your folder and the folders above it, the start of auto memory, and short lists of skills and tools.

When Claude needs it

The full skill, tool details, files it reads, and rules or CLAUDE.md files in subfolders.

In the background

Settings and hooks work outside the conversation. Subagents use their own separate workspace.

  1. Should it always apply? Use the smallest CLAUDE.md that covers it.
  2. Is it a procedure you repeat? Make it a skill.
  3. Can it never have exceptions? Use settings or a hook.
