# External steps

Before the first step, verify:

1. The starting URL.
2. That the action is needed, because the current state isn't already right.
3. Whether it can be undone, and how to undo it.

Then give one step at a time. Wait for Shela to finish each step before giving the next.

Ask for a screenshot only when files, APIs or the current context can't show the state.
