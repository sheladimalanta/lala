# Publish check

1. Confirm the right site, account and area. Check the area's `accounts.md`.
2. Check the content in preview. Check links when possible.
3. Code sites: confirm the repo and branch, and build locally.
4. Ask Shela for approval. Never publish or send without it. Cobalt work stays on hold until Shela confirms approval.
5. Publish. Code sites: commit only the intended files and push to the correct remote.
6. Confirm the live page or sent issue shows the expected content.
7. Record rejected or partial work in the project's `notes.md` so it isn't published later.
