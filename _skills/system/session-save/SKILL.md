# Session save

1. Write one new file: `~/lala/areas/<area>/sessions/YYYY-MM-DD-HHMM-<tool>-<short-id>.md`. `<tool>` is claude or codex. `<short-id>` is the session ID if the tool shows one, otherwise a short slug of the task. If the session didn't start in an area, ask Shela where to save it.
2. Never edit another session's file. If the file already exists, stop.
3. Use these sections, in order. Write "None observed" in any empty section:
   Summary, Original Request, Work Completed, Artifacts And Paths, Decisions Made, Shela Signals, Verification, Process Lessons, Open Follow-Ups, Retrieval Tags, Save State.
4. Under Shela Signals, tag each item as one of: correction, preference, quality_bar, rejection, approval, friction, decision, personal_pattern, process_fix.
5. Paraphrase tightly. Quote only when needed to keep a rule exact.
6. Then list the signals worth keeping, and offer the setup-keeper skill for each.
