# 06_maintain

Runs after the release is live.

## One job

Hand the app to its owner, with a way to see when it fails.

## What it reads

`intent.md`, `work/01_build-app/05_deploy/release.md`.

## What it does

1. Name the owner.
2. Set up the smallest monitoring that catches failure against the success criteria.
   AI apps also feed real failures back into the evals.
3. Give users a way to report problems.
4. Write the reflection the 4D assessment asks for: what was missed, what to change.

## What it writes

`work/01_build-app/06_maintain/runbook.md`, ending with Skills used.

## The human check

Who owns it, and which signal reopens the work? A reopening starts a new project or
returns to the stage that owns the problem, on purpose.
