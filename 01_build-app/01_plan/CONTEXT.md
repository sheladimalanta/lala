# 01_plan

Where the lane starts.

## One job

Write `intent.md` from the real workflow, not from the request alone.

## What it reads

The request and `source/`. If no record exists, ask Shela for a short project id
and whether to create `projects/<id>/` from `~/lala/_templates/project/`. Then run
`git init` in it.

## Load and skip

Load `~/lala/_shared/PONYTAIL-GATES.md`. Skip code, frameworks and tools.

## What it does

1. Ask who does this work today, then watch or walk through a real case.
2. List the exceptions the request did not mention.
3. Write success criteria that are specific, measurable, achievable and relevant.
4. Walk the Senior Dev Ladder. Choose the simplest useful slice.
5. Decide whether it needs AI. If so, choose automation, augmentation or agency,
   and start with the simplest option that works.
6. Choose the app class.

## What it writes

`work/01_build-app/01_plan/intent.md`, with these headings: Workflow today,
Exceptions, Success criteria, Smallest slice, AI use, App class, Skills used.

Record choices and rejected options in `decisions.md`.

## Standard

`~/lala/_shared/standards/SOURCES.md`, row `01_plan`.

## The human check before anything moves on

What result proves this worked, and which exception did the request not mention?
If `intent.md` cannot answer both, this stage is not done.
